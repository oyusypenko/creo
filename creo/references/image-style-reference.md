# Image Style Reference

## Brand Visual Identity

### Target Audience Personas

Define your target personas here:
1. **Persona 1** - Description, environment, context
2. **Persona 2** - Description, environment, context
3. **Persona 3** - Description, environment, context

### Core Visual Themes

#### Theme 1: Productivity & Efficiency
- Show time being saved
- Before/after implied scenarios
- Calm, organized workspaces
- Multiple screens showing workflow

#### Theme 2: Professional Quality
- High-end equipment relevant to your product
- Studio-quality environments
- Clean, modern aesthetics
- Premium feel

#### Theme 3: Accessibility & Ease
- Intuitive interfaces (blurred)
- People successfully completing tasks
- Relaxed, confident expressions
- "It just works" feeling

## Category-Specific Prompt Patterns

### Features Category
```
[Professional setting]. [User demonstrating specific feature benefit].
[Relevant equipment showing feature in use]. [Interface hint if applicable].
[Lighting]. [Documentary-style, authentic [feature] workflow].
```

### Use Cases Category
```
[Profession-specific workspace]. [Target user persona actively working].
[Profession-specific props and equipment]. [Product element visible].
[Natural lighting for profession context]. [Authentic [profession] workflow].
```

### Landing Page
```
Hero: Wide shot of diverse professionals using product across scenarios.
OG Image: Split composition showing before/after transformation.
Mobile Hero: Close-up of hands holding smartphone showing app interface.
```

## Quality Checklist

Before finalizing a prompt, verify:

- [ ] Scene is specific and visualizable
- [ ] Setting matches target audience
- [ ] Props are relevant to the page topic
- [ ] Lighting is specified
- [ ] Style modifier is included
- [ ] No text/logos requested (except ogImage text space)
- [ ] Authentic, not stock-photo staged
- [ ] Appropriate for image type (wide for hero, focused for card)
- [ ] Includes product-relevant element where appropriate
