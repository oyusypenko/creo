# .claude/skills/creo-perf — performance harness for this project

Generated by `/creo perf init`. Everything the creo-perf harness needs to
measure THIS project lives here; the harness scripts themselves are generic
and live in the Creo perf-harness extension.

```
perf.config.sh          targets, DB access, app dirs, ordering   (edit)
scenarios/<id>.sh       one file per user-facing scenario         (edit / add)
sql-src/<runner>/*.sql  statements to EXPLAIN (compile mode)      (edit / add)
sql-calls.py            record-mode hook: runs real endpoint code (edit)
fe-interactions.json    browser interaction probes               (edit)
dashboard.json          scenario order, titles, endpoints        (edit)
column-usage.tsv        column -> read-path usage (schema audit) (optional)
hypopg-candidates.tsv   index ideas tested without creating them (optional)
creo-perf-<id>.md       project knowledge for the skill/agent    (keep current)
perf                    wrapper: ./perf <command> [args]
results/                captures (gitignored except dashboard.md)
```

## Commands

```bash
./perf preflight                       # tools, targets, scenarios
./perf audit-all before                # immutable baseline (every capture, correct order)
./perf audit-scenario s1 after-index   # re-measure one scenario after a fix
./perf audit-fe after-split            # initial load / build / Lighthouse
./perf audit-platform <label>          # backend + DB config facts (one-time)
./perf audit-schema <label>            # tables / columns / indexes / hypopg
./perf workload-pre && ./perf workload-drive && ./perf workload-post <label>
./perf dashboard                       # rebuild results/dashboard.md
```

## Rules

- A label directory is immutable once written. `before` is the baseline; new
  labels for every re-measure; `--force` only on non-baseline captures.
- Only script-to-script pairs are comparable. Never re-derive a number ad hoc.
- Never run two captures concurrently.
- Every number is labeled: direct vs proxy, warm vs cold, prod vs dev build.
