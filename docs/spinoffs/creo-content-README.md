# creo-content

AI-powered marketing content generation skill for Claude Code -- JTBD framework, pain points, i18n-ready output.

[![GitHub Stars](https://img.shields.io/github/stars/oyusypenko/creo-content?style=social)](https://github.com/oyusypenko/creo-content/stargazers)
[![MIT License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

---

## What It Does

Run `/creo-content <page-type>` and get production-ready marketing copy:

- **JTBD Framework** -- Jobs-to-be-done based messaging
- **Customer Pain Points** -- Problem-aware headlines and subheadings
- **Page Types** -- Landing, pricing, about, features, blog
- **i18n-Ready** -- JSON output format for easy localization
- **Conversion-Optimized** -- CTAs, social proof blocks, objection handling

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/oyusypenko/creo-content/main/install.sh | bash
```

## Usage

```
/creo-content landing                         # Landing page copy
/creo-content pricing                         # Pricing page copy
/creo-content features                        # Features page copy
```
